**Where Every Wish Finds Its Way.**

A celebration and wishlist platform I'm building to make meaningful gifting more personal. It is designed to let people create celebrations, share wishlists, and bring friends and family together around shared dreams.

### 🩺 [Diabetes Progression Metrics](https://github.com/lipikaverse/diabetes-)

A beginner-friendly Python data analysis project using the Kaggle Diabetes Prediction Dataset. It compares diabetic and non-diabetic groups by calculating average BMI and blood glucose levels.

- Loads and analyses dataset records using Pandas.
- Separates diabetic and non-diabetic groups.
- Calculates patient counts and average BMI.
- Compares average blood glucose levels between the groups.

**Tech:** Python · Pandas · CSV Data Analysis

[View Repository](https://github.com/lipikaverse/diabetes-)
